# runClient 验证记录

## 验证环境

- Minecraft 1.20.1
- Forge 47.4.23
- Java 17
- JEI 15.20.0.130（开发运行时依赖）

## 结果

本次在用户明确要求下运行了 `runClient`。客户端完成 Forge、Aether、GeckoLib 和本模组加载，日志出现 `Connected to a modded server.`、玩家登录实体 ID、`Starting JEI`、`Adding 1952 ingredients` 和 `Loaded 2 advancements`，随后进入新的集成世界并保存暂停。客户端已停止，未留下 Forge 客户端进程。

这证明启动、注册同步、创造物品栏加载和 JEI 初始化通过；不等于所有实体技能、粒子、投射物绘制和 Boss 阶段都已完成游戏内验收。

## 日志中的剩余问题

- 本记录对应旧构建产物；音频引用和专用模型是在本记录之后补齐的，需要用户明确授权后重新运行客户端确认。
- 上一次运行时 `crystalite_golem` 的 `groundslam` 和 `death` 动画曾因 MCreator 赋值表达式产生解析错误；这些表达式已在源码中改为等值关键帧数值，但本记录对应的旧构建产物，尚未重新运行确认。
- 本次运行使用的是本轮源代码修改前的构建产物；自定义粒子 provider、投射物绘制、攻击/死亡技能控制器、事件 procedure、龙碰撞行为和专用模型已在源码中补齐，但尚未重新编译并再次运行客户端。
