# Aether Bedrock Mobs Reborn 26.1.2 迁移与服务端验证

本分支将 1.21.1 NeoForge 的生物扩展迁移至 Minecraft 26.1.2，继续依赖独立的 Aether Dragon，并使用 The Aether II 提供天境维度。此记录同时覆盖迁移后的简化实现检查与服务端验收。

## 环境与范围

分支为 `2612neoforge`，开发环境为 Java 25、Gradle 9.4.0、NeoForge 26.1.2.99、GeckoLib 5.5.1 和 Aether II 26.1.2 alpha.4.1。独立巨龙来自同级 `天境巨龙/2612-neoforge-天境巨龙-worktree` 的最新构建。

本模组保留 13 种生物、5 类技能实体、2 种投射物、56 个方块、83 个物品、13 个配方和6个进度。巨龙实体、巨龙技能及专属资源由独立模组提供；其他 Boss 共用的震地、光束和粒子逻辑保留为通用实现。

## 迁移对应关系

| 内容 | 26.1.2 实现 |
|---|---|
| 实体存档 | 使用 ValueInput 和 ValueOutput，保留健康、装备、狂暴状态及 UUID |
| 实体生成与注册 | 使用目标版本实体创建原因和注册键；巨龙召唤指向 aether_dragon:aetherdragon |
| 技能伤害与命中 | 使用当前服务端伤害接口、真实实体碰撞和完整技能时间轴 |
| GeckoLib | 迁移至 5.5.1 的状态提取及渲染任务提交接口 |
| 技能与粒子渲染 | 提取几何后提交，保留原面片、光束、预警、冲击波和震地效果 |
| 数据资源 | 使用 recipe、advancement、loot_table、structure 和单数标签目录 |
| 方块及物品 | 保留碰撞、掉落、武器、装备属性、格挡与刷怪蛋行为 |
| 世界生成 | 用 Aether II 的 the_aether 群系标签承接选址；保留生成权重、数量、布局与间距 |

The Aether II 的群系体系与旧 Aether 不同，新的选址范围存在变化。结构生成与实际放置已测试；长期自然分布和探索体验仍需游戏内观察。

## 简化实现检查与修复

发现独立巨龙的旧 26.1.2 技能辅助类只在生成位置附近扣血并发射粒子，缺少羽刃飞行、陨晶坠落、落雷延迟和晶棘生命周期。已根据完整的 1.21.1 实现恢复真实技能实体、碰撞、时序、生命周期及配套客户端渲染，保留攻击属性与配置倍率计算。

同时修复了本模组巨龙召唤方块查询错误注册表的问题，以及盐晶工具破损事件发给被攻击者的问题。移除重复巨龙代码后，其他 Boss 的技能同步、特效和注册仍通过服务端复测。

## 验证证据

完整服务端复测共 535 项断言，全部通过。覆盖全部生物的生成、伤害、死亡、装备和存档，5 个 Boss 的 35 个技能时间轴、自然 AI、无敌及减伤，独立巨龙的 14 个技能时间轴及远程命中，武器、刷怪蛋、食物、方块掉落、配方、进度触发和创造物品栏数据。

独立巨龙专项回归共 34 项断言，全部通过，包括 12 格羽刃命中、26 格陨晶坠落、落雷预警、晶棘伤害、攻击属性变化、发射者移除后的伤害快照、墙体阻挡、技能清理、50% 血量判定和击退抗性。

最新依赖包的天境维度复测共 70 项，存档重启和完整资源重载共 37 项，均通过。正式 JAR 独立加载成功，重载后读取了全部 14 个存档生物的生命值，保存并正常停服。正式包不包含临时测试类。详细日志与包校验值见 [服务端验收记录](server-validation-26.1.2.md)。

原始结果及日志保存在 `D:/AI临时文件/aether-reborn-2612/full-server-tests`。客户端未启动；构建通过与服务端命中验证不代表视觉效果已经游戏内验收。Aether II 注册 GuidebookToastPacket 时有两条 Toast 客户端类加载诊断，调用栈已定位至该依赖，未阻断专用服务端运行。
