## S0 证据恢复进展

已取得 Modrinth 项目 `6NmqryJl` 的正式版本 `HFN7qFQM`：`aethermobs-1.5.0-forge-1.20.1.jar`。JAR 的 `mods.toml`、`net/mcreator/aethermobs/` 包名和 MCreator credits 已确认原实现确实来自 MCreator。

原 JAR 盘点为 28 个实体类型；当前迁移注册 27 个实体类型（Dragon 二阶段已并入 `aetherdragon`，不保留旧 ID）、56 个方块、14 个普通物品、25 个刷怪蛋、6 套结构和 15 个生物群系生成修饰器。完整清单见 [JAR 功能清单](./evidence-inventory.md)，来源和哈希见 [原始发布证据索引](../evidence/source-index.md)。

S0 的输入证据基线已建立；原始 MCreator 工程缺失，因此实体专属攻击、部分掉落条件和结构内部连接仍需以 JAR 字节码、NBT 和资源逐项复核。

## 迁移原则

1. 不迁移 MCreator 生成的 Java 结构；只提取其可验证的功能、注册内容、资源、数值和数据关系。
2. 先建立“原功能清单”，再设计注册表、实体、世界生成和渲染架构。
3. 保留原模组已有功能；新版本不以删减功能换取快速完成。
4. 所有不确定内容标为“待确认”，不得把推测写成已实现行为。
5. 默认只做 Minecraft 1.20.1 Forge；不在本轮额外兼容其他 Minecraft 版本或加载器。
6. MCreator 工程、正式 JAR、资源包、截图和运行记录都属于证据来源；优先级按“源码/工程 > JAR/字节码 > 资源与数据 > 页面描述 > 推测”处理。

## 当前阻塞项

原始正式 JAR 已取得，当前进入 S2 内容重写；以下项目仍会影响完整功能等价或最终验收：

- 原始 MCreator 工程缺失，无法直接核对未进入发布 JAR 的编辑器配置。

- 客户端运行、专用服务端数据加载和结构生成尚未执行；`gradlew build` 成功不等于玩法验收完成。
