# 天境巨龙钥匙召唤

安装本模组后，地牢中的天境巨龙通过主手持有 `终末之钥 / Final key`（`aether_bedrock_mobs_reborn:finalkey`）右键巨龙刷怪器召唤。空手、错误物品、副手、旁观者以及无玩家激活不会召唤；靠近不会自动召唤。

新生成的本模组天境巨龙地牢使用结构规则处理器，将外部自动刷怪器和该结构中的六个巨龙刷怪笼换成本模组钥匙刷怪器。已有地牢中的外部自动刷怪器在独立模组的接近检测之前转换；原版巨龙刷怪笼在区块载入后转换，并用生成位置检查阻止转换前的自动刷怪。右键转换路径同样先检查钥匙。其他生物的原版刷怪笼保持原行为。

区块处理只遍历已有方块实体位置，不扫描整个区块；现有每秒玩家附近检测沿用原范围。钥匙沿用原有可重复使用方式，不额外消耗。召唤成功后该刷怪器消失；激活前确认刷怪器仍在，防止同一位置重复召唤。独立模组 AI、已存在巨龙、管理员命令及创造模式刷怪蛋未改动。

终末之钥原合成配方保留：4 把城市钥匙，加燔祭长矛、盐蟹乐器、水晶石剑、地牢匕首和灵魂之剑，产出 1 把终末之钥。

验证关注：空手靠近、空手右键、错误物品、副手钥匙、主手钥匙、重复激活、旧刷怪器及旧原版刷怪笼、新生成地牢的全部七个入口、普通生物刷怪笼不受影响。

右键兼容处理采用最低事件优先级，并保留其他模组取消交互的机制；被领地保护等模组取消的右键不会召唤巨龙。原版龙刷怪位置检查也在其他位置条件之后明确拒绝，玩家接近的方块转换仍先于独立模组的检测。
